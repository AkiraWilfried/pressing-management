# Frontend — Pressing

Client React + Vite de l'application Pressing.
Installation, configuration et démarrage : voir le [README racine](../README.md).

```bash
npm install
npm run dev
```

`src/app/lib/store.ts` gère le mode hors-ligne, `src/app/lib/api.ts` les appels REST
activés par `VITE_USE_API=true`.
